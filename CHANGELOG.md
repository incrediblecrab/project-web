# Change Log

All notable changes to the "Project Web" extension will be documented in this file.

## [1.0.1] - 2025-06-09

### Production Release
- Updated project name to "Project Web" for consistency
- Production ready release with improved stability
- Enhanced documentation and branding updates

## [0.0.1] - 2025-05-25

### Initial Release
- Interactive graph visualization of workspace file structure
- 6 layout options: Force-directed, Tree, Circle, Grid, Concentric, and Dagre
- Click-to-open file functionality
- Advanced search with result navigation
- Comprehensive theme customization (colors, fonts, background)
- File and folder filtering options
- Export functionality (SVG, PNG, JSON)
- Full VS Code theme integration
- Responsive UI design
- Local-only operation (no external dependencies)
